# SoSe25 – Mobile Computing (HS Bremen, Summer Semester 2025)

This repository contains example code and materials of the iOS lecture "Mobile Computing" at Hochschule Bremen for the summer semester 2025. The course covers various topics in mobile app development using Swift and SwiftUI.

---

**Contents of the `SoSe25/` directory:**

- `Lecture 1/`  
  Example code and materials for the first lecture session.

- `Lecture 2/`  
  Example code and materials for the second lecture session.

- `SoSe25App.swift`  
  Entry point of the SwiftUI app. You can switch between the different lecture examples.

---

**Requirements:**

- Xcode 15 or newer
- macOS Ventura or newer
- Basic knowledge of Swift and SwiftUI

---

**How to get started:**

1. Clone the repository:
   ```bash
   git clone https://github.com/ilyas-hallak/HSBremen_MobileComputing_SoSe25.git
   ```
2. Open the Xcode project in the `SoSe25` folder:
   - Double-click `SoSe25.xcodeproj` (if available) or open the folder in Xcode.
3. You can run the app directly in the simulator or on a real device.

---

**Note:**  
The subfolders `Lecture 1` and `Lecture 2` each contain example projects or code snippets that will be discussed during the lectures. Updates and additions will be made throughout the semester.

Happy coding and learning!
